## Folder layout
```
data/
  raw/        original files from UCI, never edited (hour.csv, day.csv, Readme.txt)
  processed/  files generated by the pipeline (re-creatable, not committed)
```

## How to obtain the data
1. Download the zip from the direct-download link above.
2. Extract `hour.csv`, `day.csv` and `Readme.txt` into `data/raw/`.
3. Verify: `python -m src.data_loader` — this validates the schema and prints a summary;
   it stops with an error if the file does not match the official format.

`hour.csv` is the primary file (one row per hour). `day.csv` is the daily aggregate,
kept for reference only.

## Original vs derived columns
- **Original (17 columns, from UCI):** instant, dteday, season, yr, mnth, hr, holiday,
  weekday, workingday, weathersit, temp, atemp, hum, windspeed, casual, registered, cnt
- **Derived by this project** (documented as they are added): `datetime` (sorting/splitting
  helper, not a feature), `demand_level` (classification label), engineered features.
